# 沐风视觉规范：现代人文编辑风格

适用于沐风文章的封面、正文配图与公众号排版。用户当前指定的风格和适用 AGENTS.md 优先；本规范不授权生图、上传或发布。只处理文章文字时无需加载。

## 默认方向与题材变体

以现代杂志的清晰秩序为骨架，保留适量纸感、墨色和自然留白。典雅落实为主体明确、比例协调、颜色克制与阅读清楚，不依赖金属质感或古典装饰。

| 题材 | 视觉方向 | 画面语言 |
|---|---|---|
| 默认、AI 工具、成长 | 现代人文编辑风格 | 平面编辑插画或轻版画质感，明确的轮廓，少量手工笔触 |
| 读书、传统文化 | 轻水彩与东方书卷气 | 柔和笔触、淡墨与浅赭；具体物象来自文章，不固定添加山水、竹叶、印章 |
| 技术机制、投资数据 | 理性极简出版风格 | 白底、细线、清晰网格、单一强调色；精确关系用确定性绘图 |

三种变体共用正文排版与基本色板。实物、人物或场景只有在服务文章时才加入；摄影或静物需要具体理由，不再默认电脑、书本、金币、服务器堆叠或仿 3D 渲染。

基础色板：暖白 `#F7F5EF`、墨色 `#292D2B`、青绿 `#59766C`，赭红 `#A2604F` 仅少量使用。每幅画默认中性色加一个强调色；无需每篇用齐。它们是本轮采用的初始规范，后续按用户样张反馈调整。数据图保留必要的类别区别和足够对比，不为低饱和牺牲可读性。

## 先确定图片的任务

- 封面负责建立主题印象。默认无字，画面本身必须完整；不强制叠加标题。
- 解释图负责说明一个附近概念。准确箭头、数值、标签、坐标和状态使用确定性绘图，导出发布所需 PNG；不要让生图模型猜测。
- 证据图使用真实截图或原始文档。可以裁切和必要脱敏，但保留原图，说明来源、页码或必要上下文；不得生成替代证据。
- 不按每隔多少字或每个章节机械配图。封面之外，每张图需说明它增加了什么理解或证据；文字已经说清且图无新增作用时省略。

## 构图与文字

- 每幅画表现一个主要关系，默认一个主体，最多两组辅助元素。文章关键词不必全部入画。
- 无字封面不强制左空右实。留白应与主体形状、视线方向和版面节奏相配，避免大面积空白加角落小物件。
- 横向封面默认 2.35:1；其他比例按目标渠道或用户要求选择。关键主体尽量位于中心方形裁切可保留的区域，实际检查后再确认可用。
- 需要标题时，先确定标题长度和排版区域，再生成无字底图；标题由独立排版层添加，不能让模型生成可读文字后再覆盖修补错字。
- 普通无字封面不为“以后也许加标题”预留半张空白。正文图按解释需要选比例，不照搬横幅构图。
- 同篇共享色板与线条语言，按图片任务变化视角与结构。跨篇维持身份一致，避免机械复制同一隐喻；不要为追求不同而每篇更换整套品牌颜色。
- 禁止伪造 UI、代码和 Logo，以及无关的霓虹光网、机器人、全息屏、粒子、塑料 3D、金属球和设备堆叠。纸纹与阴影仅作轻微辅助，不让画面灰暗、脏浊或细节拥挤。

## 提示词与参考记录

生成前在当前项目 `imgs/<article-slug>/prompts/` 保存完整提示词，每张单独一个 Markdown 文件；采用的参考图片也存入项目，记录来源和用途。没有参考图时如实记录，不声称已比较样张。

提示词分别写清：

1. 用途与邻近段落：图片要帮助读者理解什么。
2. 主体关系：一个核心关系与必要物象，不照字面堆砌所有隐喻。
3. 画法：选定题材变体、线条、笔触或材质。
4. 构图：比例、主体大小、位置、留白用途、裁切区域；有标题时给出独立文字区域。
5. 色板：背景、主色与强调色，保持明暗分离。
6. 参考：每张参考图用于画法、颜色还是构图，不复制无关内容。
7. 约束：无文字、水印、伪 UI 与相关禁用元素；概念图不暗示未经证实的数据比例。

第一次校准风格时，可在用户已授权生图的范围内用同一主题比较两种画法。之后复用已选方向，不要求每篇批量试图。

例：现金流文章可用墨色线条表现资金流动，在投入处分流，少量青绿色表现可留下的部分。避免写实金币和服务器堆叠。该画面只表达资金分配，不代表真实金额或比例；准确数值另做数据图。

## 公众号正文排版

以下是预览时的初值，不是平台硬性标准；用户指定主题优先。

| 项目 | 初值 |
|---|---|
| 正文 | 16–17px，系统无衬线字体，深灰，白底 |
| 行高 | 1.75–1.85 |
| 字间距 | 0–0.03em |
| 段间距 | 约 1–1.2em |
| 二级标题 | 左对齐、20–22px、墨色，避免默认蓝底白字色块 |
| 标题间距 | 上约 2–2.5em，下约 0.8–1em |
| 强调 | 字重优先，品牌色只强调少量真正关键内容 |
| 引用 | 细线或浅底二选一，避免多层卡片 |
| 图注 | 12–13px、清楚的灰色，交代图意或来源 |

标题宋体仅在确认真实字体回退后采用，正文优先跨设备稳定。证据图局部阅读版保留必要表头、单位、日期和来源，不把整页缩小后的小字当作可读证据。

### 与现有发布器配合

- 先检查用户当前要求、文章 frontmatter 和账户主题偏好；没有明确指定时，以发布器支持的 `modern` 主题、青绿强调色 `#59766C` 为起点。不要修改全局 EXTEND.md。
- 使用前检查当前发布器的 `--help` 或源码，确认主题及颜色参数；不得编造自定义 CSS 参数。本次核查的发布器支持 `--theme modern --color '#59766C'`，不代表其他安装版本都支持这些参数，也不代表能逐项实现上表全部数值；运行时以实际安装版本为准。
- 保持现有 Markdown 直发流程。需要预览时，只在项目本地调用渲染器生成 HTML 并检查，不为预览上传草稿；不修改官方插件缓存，不擅自切换 HTML 发布。
- 本次核查的主题源码显示：`simple` 仍有装饰性圆角与阴影；`modern` 的二级标题左对齐，较接近目标，但容器行高为 2，带圆角和内边距，仍不等于上表的定制版式。
- 标准主题无法表达的参数，列为版式差异；若仍清楚可读，可使用最接近的受支持主题并披露差异。实质遮挡、溢出或小字不可读应先修正。若需新渲染代码或模板文件，另列范围，不借本规范扩大改动。

## 交付验收

生成或调整视觉资产后再检查，不能把规则检查说成审美验证：

- 图像缩到约 320px 宽，主体与主要关系仍能识别。
- 检查横幅和中心方形裁切；关键主体不丢失，不为了兼容所有裁切把画面缩成小图标。
- 无字封面像完整作品；有字版本检查独立排版层的字形、对比和边距。
- 正文在 375px、430px 宽预览，标题层级、换行、表格和图片文字可读，没有横向溢出。
- 封面、解释图与正文配色协调；证据截图无需强行改成品牌色。
- 每张图片都有明确任务；解释图不冒充证据，概念关系不冒充精确比例。
- 交付或引用的图片与提示词保留在当前项目。使用内置 ImageGen 后，先递归确认生成源 PNG 存在且非空，立即复制到项目目标路径并验证非空，才可引用或继续下一张。
- 记录实际执行的检查、用户选定方向和未验证项。没有样张或手机预览时，明确写“视觉效果尚未验证”，不宣称已经更好看。
