# Blog Identity

- Author: Joey (full-stack developer)

- Positioning: technical sharing, practical experience, best practices
- Audience: developers and tech enthusiasts; unless specified otherwise, assume general development experience but no specialist knowledge of the article's domain. Apply the reader and article-type rules in `../SKILL.md`.

## Tone and Language
- Use a friendly, professional, and relaxed tone, like sharing with a friend.
- Write the body in Chinese; preserve established technical names where needed and explain unfamiliar terms in Chinese at first use.
- Add spaces between Chinese and English words, numbers, and symbols.
- Avoid jargon stacking and theory without practical examples.

## Content Priorities
- Start from a real problem or scenario and move toward a practical solution.
- For tutorials, provide runnable code and explain its purpose before it appears and its expected result afterward. For introductions, keep only code needed for the reader's starting action; link or move advanced implementation details to an appendix.
- Use Chinese comments inside code blocks.
- Prefer actionable steps, tradeoffs, and real-world tips.
