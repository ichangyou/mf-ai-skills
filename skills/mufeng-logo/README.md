# mufeng-logo

为原创品牌 Logo 提供从真实上下文到可用源文件的工作流，支持图形标、字标、图文组合和已有 Logo 精修。
Codex 与 Claude Code 共用同一份正文，独立使用，不要求其他 skill 或固定设计服务。

## 安装与调用

在本仓库根目录执行：

```bash
python3 scripts/install.py --platform both --scope user --skill mufeng-logo
```

安装器不覆盖已有同名目录。项目级、复制安装见[安装文档](../../docs/installation.md)。安装后重新加载 skills 或重启客户端。

Codex：

```text
$mufeng-logo 为当前产品设计原创 Logo。先读产品和品牌材料，比较三个可视方向，自主推荐并精修，交付矢量源和单色、反白、小尺寸检查。
```

Claude Code：

```text
/mufeng-logo 优化这个品牌字标，保留名称和整体气质，调整字距并交付可编辑文字源、实际转曲版本和透明 PNG。
```

想先确定方向时加“给出可视候选后等我选择”。想定点修改时说明保留项；流程不会强制重新设计整套品牌。
没有项目时指定品牌材料和输出目录；缺少名称、核心用途等关键信息时会询问。

## 能力与边界

- 从产品和品牌定位提炼方向，比较真实图形或文字结构。
- 精修轮廓、负空间、视觉重量、字形、字距与图文比例。
- 按用途交付主版本、单色、反白和必要组合，保持真实长宽比。
- 检查实际源文件、小尺寸、透明边缘、字体依赖与目标载体。
- 本 skill 专注 Logo；App icon 使用 `mufeng-app-icon`，不会自动把 Logo 装进圆角方块。

## 工具条件

文件读写是基本能力；实际视觉验证需要可用的 SVG/设计文件渲染器和图片查看能力。
简单几何可制作真实矢量；复杂图形可通过宿主可用的生图/绘图工具探索，再按能力实际重绘或转成路径。
字标转曲需要实际字体和支持该操作的工具；两端不保证拥有同样的字体、设计软件或生图服务。
本 skill 不安装依赖，不附带字体/第三方品牌资产，也不硬编码工具名称与路径。
缺少工具时明确哪些产物或检查没完成，不用提示词冒充图像，也不用内嵌 PNG 的 SVG 冒充矢量母版。

## 交付

通常包括项目内的源文件、用途需要的版本与导出、检查图和简短使用说明。
有文字源就说明字体依赖；有转曲版就说明实际是否检查过。所有采用图片与交付文件存入目标项目。
设计范围不自动扩展到完整 VI、品牌改名、网站改版或商标调查，不承诺可注册或绝对独创。

执行入口见 [SKILL.md](SKILL.md)，细则在 `references/` 按需加载。
本工作流独立编写，按仓库 [MIT 许可](../../LICENSE)提供，不复制第三方品牌素材。
