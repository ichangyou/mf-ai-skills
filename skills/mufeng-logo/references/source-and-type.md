# 源文件、文字与制作

## 工具选择

使用当前宿主实际提供的绘图、文件编辑、图片生成和查看能力，不猜工具名或 API。
Codex 有内置生图能力时可用来探索；Claude Code 使用真实配置的工具。没有生图服务不妨碍制作几何矢量或字标，但不能把提示词当成图像成果。
遵守宿主的生成与编辑规则。编辑时先查看原图，用可用工具支持的参考图机制，不声称保留了实际无法保留的细节。

## 矢量与栅格

SVG/PDF 是容器类型，不自动证明里面的 Logo 是可编辑矢量。
检查源文件实际包含的路径、形状、文字与图片引用；将 PNG 装进 SVG 不会变成矢量母版。
几何设计保留可编辑路径与合理分组。自动描摹后检查噪点、转角、负空间和路径数量；不要把转换成功视为精修完成。

生图适合探索形状与气质。需要最终矢量时实际重绘/转成路径并查看结果；能力不足则交付栅格概念并明确矢量尚未完成。
生成的字母和文字必须逐字核对；字标优先使用真实字体或实际绘制的字形，不默认接受生成图上的近似拼写。

## 字体与字标

- 采用项目已有或实际可用的字体；记录 family、字重、版本/来源和已知许可条件，不凭空声称可商用。
- 核查准确拼写、大小写、重音、数字、中文及其他语言字形，不能悄悄替换成相似字符。
- 留一份可编辑文字源。使用者没有字体时，字体可能替换，交付说明应明确依赖。
- 需要无字体依赖的视觉版本时，用真实可用工具转曲并另存，不能仅将 SVG 的 text 元素改名为 path。
- 实际渲染转曲前后版本，核对字形、字距、基线与边界是否变化；保留文字源而非只留轮廓。
- 不自动把字体文件随包分发。许可不明时记录缺口，仍可交付现有成果，不能冒称完整无依赖包。

SVG 文字与嵌入内容的格式依据按需查阅 [W3C SVG Text](https://www.w3.org/TR/SVG2/text.html) 和 [Embedded Content](https://www.w3.org/TR/SVG2/embedded.html)；它们不代替实际渲染。

## 导出

按用途选择 SVG、PDF 或透明 PNG，保持原始长宽比；不将横向字标压成正方形。
SVG 设置覆盖真实画面的 viewBox，检查笔画、滤镜与裁切区域。分组和颜色易于后续修改，去除不必要的外部文件/字体依赖，无法去除时明确记录。
PNG 明确像素尺寸和背景条件。预览中的棋盘格不能烘焙进透明交付物。

默认数字色彩以实际使用的 sRGB 数值记录；不要声称导出普通 PDF 就获得印刷 CMYK 或专色保证。用户需要印刷时按印厂要求实际转换和打样，缺少条件则注明未验证。
不为了齐全而创建当前用途不需要的几十种尺寸、配色和组合。

## 保存

采用目标项目已有品牌目录；没有约定时可用 `design/logo/` 下的 source、exports 与 review，按需创建。
采用或交付的图片一律存入目标项目；工具生成后确认源非空，复制项目副本并验证，再引用或继续下一张。
源文件与导出文件分开命名，不覆盖用户原有资产。记录真实工具与素材来源，不携带第三方品牌资产。
